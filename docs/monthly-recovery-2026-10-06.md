## 원인과 조치

- 월간 작업이 임시 API 캐시만 새로 채우고 주민등록인구 DB 적재와 AI 보고서 생성은 실행하지 않았다. 원천 검증 → 월자료 추가 → 조회 검증 → 보고서 생성·저장·배포 API 재조회로 연결했다.
- 다른 스냅샷의 이전 보고서를 정상 캐시로 취급해 새 보고서 생성을 막았다. 이전 생성본을 구분하고 대상월·행사·같은 월의 비교 인구를 스냅샷에 포함했다.
- 운영체제에 따라 해시 키 정렬이 달라졌다. 재귀적으로 동일한 순서로 정규화해 Windows 작업과 배포 함수가 같은 키를 사용한다.
- 도서관 인구를 동 이름만으로 결합해 같은 이름의 다른 자치구나 다른 기준월이 섞였다. 자치구+동 식별과 최신 동일 월 집계로 수정했다. KOSIS의 `제` 표기 및 용신동 원천 단위도 대응한다.
- 지역 선택을 빠르게 바꾸면 늦게 도착한 이전 응답이 화면을 덮어썼다. 이전 요청 취소와 최신 요청 확인을 적용했다.
- 긴 AI 생성을 배포 HTTP 호출로 실행하면 연결 제한으로 저장 후에도 실패할 수 있었다. 자동 작업에서 직접 생성하고, 배포 API는 저장 결과를 재조회하여 검증한다.
